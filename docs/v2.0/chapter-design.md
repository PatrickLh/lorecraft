# 身世悬疑章节：玄灯旧案

## 本次实现范围

新开一世默认进入《故纸藏灯》。旧存档不会自动迁移，游玩页可主动进入；保留原日期、数值、出身、身世、武学、记忆和历史。章节期限从进入时刻起算，不能通过重复进入重置。

第一章由固定事实、可检查的条件和世界日程驱动。核心流程不调用 LLM，不再生成当天全部分支。可选“细读上一幕”才会调用叙事模型，只扩写已发生的事实，不发奖励或推进任务。NPC 当前采用固定话题与任务选择，尚未实现三轮自由对话与 LLM 好感判定。

## 地图与人物

两座主城为钱塘、临安。城内节点六处，城外地点六处：芦苇渡、玄灯庄遗址、黑松林、水关驿道、青竹试剑坪、归云祠。同城移动一时辰，跨城两时辰；查看地图、目标和人物不耗时。

二十名可预见人物均有公开背景、个人目标、喜好、底线、所在地与关系。详情见 `packages/worlddata/src/content/chapter.ts`。名册展示公开身份，证据和具体旧案答案通过实际任务取得。会谈、证人离开等情况由世界进度控制。第一次实际接触会同步到现有人物图谱；同人同日兴趣交谈的信任只增加一次。

## 主线与日程

| 节点 | 主动路线 | 拒绝或错过 |
| --- | --- | --- |
| 旧物上的云雷纹 | 决定追查周劲 | 不主动接下调查，等待公开消息的其他入口 |
| 周劲的夜镖簿 | 三日内到镖局，帮工或以身手担保取得证词 | 三日后旧簿销毁，传闻仍指向芦苇渡 |
| 温九要离开了 | 六日内到渡口，可安排证人安全离开并取得签押证词 | 船夫离开，公开告示仍指向玄灯庄遗址 |
| 玄灯庄余烬 | 章节开始两日后，靠智力或武力完整取证；能力不足可抄线索 | 不会因数值不足卡死，但无完整物证不能公开洗冤 |
| 临安副卷 | 十一日内，以五两抄录费或白露引荐换正式副本 | 可只听转述；到期封卷，仍能得知归云祠会谈 |
| 归云祠的灯 | 开始四日后可会面，十三日后结束 | 不赴约也产生公开结果，不冻结世界 |

期限均为相对进入章节的实际时辰数，界面显示绝对日期，截止时刻不可再参与。跨时辰行动造成错过时，消息记录事件实际截止时间。

## 分支结果

- **灯照归名**：实际取得原账与正式副卷，公开洗去家人的匪籍。
- **未尽的案卷**：交出已有线索，进入重查，但不虚构证据齐备或公开改判。
- **收灯入怀**：接受十五两补偿，放下公开追查，公文未改。
- **独行知归**：不替任何一方背书，保留自己的判断。
- **未赴的灯约**：会谈按日程结束，玩家从消息得知证据不足的处理。

这些是章节结果，不是人生终结；玩家仍可谋生、修行、探索支线。第二章尚未开放。

## 人物支线与数值

六个支线节点包括灶房交班、林中采药、回春堂送药与引荐、鲁桥断刀、丁绣交接木牌、沈砚试剑。采药与送药构成一条两段任务。奖励、金钱门槛、能力要求和前置证据全部由服务器验证，完成不能重复领奖。

谋生与修行独立提供：帮工（钱 +2～3、温饱 +3）、用饭（钱 −1、温饱 +4、零时辰）、休息（气血 +3、真气 +2）、练武、读书、等候。温饱照常消耗，恢复受上限限制。无需为生计强接主线。

## 交互与验证

阅读区显示当前具体场景，底部为该事件的真实选项；“目标 / 地图 / 人物 / 消息 / 谋生修行”打开独立手册，不挤占阅读视口。任务显示前往地点、开放时间、期限与条件；不满足的选项保留理由。

自动测试覆盖完整洗冤路线、三种主动分支、缺席世界结局、旧存档保留、默认新档、条件防绕过、重复请求、奖励防重复、NPC 离开、信任限制、跨城时间与刷新恢复。核心故事推进测试断言模型调用为零。
